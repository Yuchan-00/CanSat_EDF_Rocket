# 06. 펌웨어 상태도 (FCU onboard supervisor)

이 상태도는 펌웨어 `firmware/atmega128_fc/src/core/onboard.c`(`body-redesign` @ 78f59fa)를 그대로 옮긴 것입니다. 이 C 코드는 Python 감독기 `sim/onboard.py`의 `OnboardSupervisor`를 틱 단위로 똑같이 포팅한 것입니다.

- **상태:** SAFE, ARMED, POWERED, UNPOWERED, RELEASED, ABORT의 6개뿐입니다.
- **예전 상태:** 예전 v0.3의 LAUNCH..LANDED 상태들은 폐기되었고 비행에 쓰이지 않습니다(`sim/state_machine.py:9-28`).
- **틱 주기:** 250 Hz(4 ms)입니다.
- **약어:** "nonce"는 16비트 LFSR 값입니다. 성공한 LAUNCH와 THROTTLE을 실행할 때마다 다음 값으로 넘어갑니다.
- **표기 (UML):** 둥근 사각형 = 상태, 채운 점 = 시작, 전이 라벨 = "사건 [가드] / 동작".
- Mermaid 원본은 [상세판](detailed/06_펌웨어_상태도.md)에 있습니다.

상태는 이 6개뿐입니다. 예전 v0.3의 LAUNCH..LANDED 상태는 폐기되었습니다(`sim/state_machine.py:9-28`). 패드에서 KILL, I1p, I9, 암 스위치로 SAFE에 들어가면 대기 중인 분리가 취소됩니다(`onboard.c:126-127`). 명령 가드는 표 6.3, 인터록 조건은 표 6.4에 있습니다.

## 6.2 한 틱 안의 감독기 처리 순서

![그림 6-2. 한 틱 안의 감독기 처리 순서 (onboard_update)](img/06_펌웨어_상태도_2.png)

**그림 6-2.** 한 틱 안의 감독기 처리 순서 (onboard_update) · [SVG](img/06_펌웨어_상태도_2.svg) · [PNG](img/06_펌웨어_상태도_2.png)

| 주 | 내용 |
|---|---|
| ① | 틱 시작: nav 프레임 도착 또는 4.6 ms 타임아웃 |
| ② | IL_CMD 큐: 틱당 최대 4 프레임, SEQ 검사. 유효 프레임은 모두 링크 타이머를 갱신하고 응답을 받습니다. 이미 처리한 SEQ는 확인 응답만 합니다. 거부된 명령도 SEQ를 소모합니다(`onboard.c:429-462`). |
| ③ | execute_ballistic: ARM / DISARM / LAUNCH / THROTTLE / CUT / RELEASE / KILL. 코드 8-11(옛 VTOL)은 REJ_UNKNOWN_CMD. 분리 대기 중에는 KILL만 수락하고 나머지는 REJ_RELEASE_PENDING. |
| ④ | 인터록 순서: 0 암 스위치 → 1 I9 → 2 I1p → 3 I1 → 4 I2 → 5 I3 → 6 I8 → 7 I5 → 8 I4 → 9 I7 → 10 I6. 처음 걸린 하나만 실행합니다(조건은 표 6.4). |
| ⑤ | 분리 타이머: 대기 중 분리 또는 ABORT 만료 → release_open, RELEASED |
| ⑥ | 스로틀 슬루: +1단계/틱, 감소는 즉시. POWERED 누적 틱 카운터를 갱신합니다. 출력은 control_active, 스로틀, 분리 열림 여부입니다. |

그림 6-2의 "시작"과 "끝" 단말은 ISO 5807 형식을 위해 넣은 것이며 새 사실은 없습니다.

## 주의

- **SEQ 처리:**
  - 유효한 프레임은 모두 링크 타이머를 갱신하고 응답을 받습니다.
  - 이미 처리한 SEQ는 확인 응답만 합니다.
  - 거부된 명령도 SEQ를 소모합니다(`onboard.c:429-462`).
- **분리 대기 취소:** 패드에서 KILL, I1p, I9, 암 스위치로 SAFE에 들어가면 대기 중인 분리가 취소됩니다(`onboard.c:126-127`).
- **회전 검사 범위:** I3은 POWERED에서만 평가합니다. 차단 후 약 1,390 °/s 스핀으로는 I3이 걸리지 않습니다. rev1 사양 메모("차단 후 발동할 수 있음")는 코드와 다릅니다(facts_fw §11 항목 7).
