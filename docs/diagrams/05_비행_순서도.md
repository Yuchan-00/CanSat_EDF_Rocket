# 05. 비행 순서도 (Mission flow: pad → landing)

이 순서도는 펌웨어 `body-redesign` @ 78f59fa(`src/core/onboard.c`)와 지상국 `sim/ground_station_logic.py`가 **실제로 구현한** 흐름을 따릅니다.

- **기호 (ISO 5807):** 둥근 단말 = 시작·끝, 직사각형 = 처리, 마름모 = 판단(예/아니오), 평행사변형 = 입출력, 양옆 이중선 상자 = 미리 정의된 처리(다른 그림에서 자세히 다룸).
- **표기**
  - 회색 채움: 지상국이 하는 일
  - 점선 상자: 계획만 있고 구현되지 않은 것, 또는 코드 밖 조건
  - 진한 빨강 선: 중단(ABORT)과 안전 경로
- **아래 숫자의 출처:** params.json mission 값을 생성한 `params_gen.h`(PG)입니다.
- Mermaid 원본은 [상세판](detailed/05_비행_순서도.md)에 있습니다.

| 주 | 내용 |
|---|---|
| ① | 비행 전 조건(코드 밖, 계획): 꼬리 링 장착 상태에서 추력 실측 25.0 N 이상. 미달이면 자유 비행 금지(20 N에서 T/W 0.981). |
| ② | 켤 때는 1S 로직 전원(J15)을 먼저 켜서 3칩 + ESP를 부팅하고, 6S는 로직 다음에 연결한다. ESC 신호 1000 µs = 정지. |
| ③ | 모든 부팅은 SAFE에서 시작한다. 모터 정지, 베인 중립, 분리 잠금을 첫 PWM 프레임부터 유지한다. |
| ④ | 패드 정렬: 정지 2 s(N_avg 500틱) 동안 각속도 각 축 < 3 °/s, 가속도 크기와 g 차이 < 0.05 g, 그리고 기압 기준 확보. 미완료 동안 LED 빠른 깜빡임. |
| ⑤ | 지상국은 최근 텔레메트리(2 s 미만)가 없으면 ARM / LAUNCH / THROTTLE을 거부한다. |
| ⑥ | ARM 게이트(이 순서로 검사): 분리 열림 아님 · 암 스위치 닫힘 · IMU·기압 정상 · 정렬됨 · 기울기 < 5° · V_cell ≥ 3.3 V · 링크 살아 있음. 실패하면 REJ 코드로 거부하고 SAFE 유지. |
| ⑦ | ARMED: 모터 정지, 베인 중립, 요 기준 = 무장 시 방위. |
| ⑧ | 패드 페일세이프: DISARM · KILL · 암 스위치 열림 · I1p 링크 2 s 끊김 · I9 센서(IMU 25틱 / 기압 125틱). 암 스위치는 KILL과 같다. |
| ⑨ | LAUNCH는 확인 + nonce 필수. POWERED: 스로틀 0 → 1.0을 0.5 s(125틱) 램프, 자세 제어 250 Hz, 베인 4장. |
| ⑩ | 비행 인터록(매 틱): I1 링크 3 s · I2 기울기 > 45° · I3 회전 > 180/720 °/s 0.02 s · I8 V_cell < 3.3 V · I5 고도 > 160 m · I9 센서 · 암 스위치 · KILL. 하나라도 발생하면 ABORT. |
| ⑪ | 지상국 보조 자동 CUT: P + max(dP/dt,0)·T_tel/2 ≥ 140 m, P = h + v_z·t_link + 1.2·v_z²/2g. 응답 타임아웃이면 외삽값으로 판정. 판단의 '예' 출구 = CUT / THROTTLE 0, '아니오' = 아직. |
| ⑫ | 탑재 차단: I4 h + 0.0612·v_z² ≥ 150 m → CUT (k = 1.2/(2g) = 0.0612). I7 추진 누적 25 s(6250틱) → CUT. |
| ⑬ | UNPOWERED(관성 상승): 스로틀 0, 0.5 s 자세 유지 후 베인 중립. 차단 후 스핀 약 1,390 °/s - I3는 POWERED에서만 평가하므로 이 스핀으로는 ABORT가 나지 않는다. |
| ⑭ | 관성 구간의 중단 요인: I1 · I5 · I9 · KILL · 암 스위치. |
| ⑮ | 지상국 보조 자동 RELEASE: 예측식 v_z - g(t_link + 0.2 + T_tel/2) ≤ 0 또는 관성 6 s 타임아웃. I6 낙하 백업: v_z ≤ -8 m/s 0.3 s(75틱) 지속. |
| ⑯ | 계획: 탑재 정점 감지 백업(기압 + 가속도 + 시간 상한), REQ:18, 미구현. |
| ⑰ | 분리 대기 0.2 s(50틱), 대기 중에는 KILL만 수락. RELEASED: 분리 서보 1999.5 µs (90°), 모터는 전원 재투입까지 정지(종단 상태). |
| ⑱ | ABORT: 모터 즉시 정지, 0.5 s(125틱) 후 분리 서보 열림 → RELEASED. |
| ⑲ | I10: 비행 중 워치독/BOD 리셋 → SAFE로 부팅, 분리 서보 열림, 전원 재투입 전 ARM 거부. |
| ⑳ | 사출: 스프링 15 N → 푸셔 → CanSat → 낙하산 팩 → 노즈 분리. 하강: 기체 낙하산 1.2 m, 약 6.26 m/s (MID), 노즈는 코드 고리에 매달림, CanSat는 자체 낙하산. |
| ㉑ | 착지: 꼬리 링 먼저, 펌웨어 착지 감지 없음, LED 느린 깜빡임 + 위치 비프. 회수: 6S 먼저 분리 → 로직 OFF, OpenLog 기록 → decode_log.py. |

**그림을 그리며 바꾼 표현 (사실은 그대로):**

- "정점 분리 판단"은 출구가 하나뿐이라 미리 정의된 처리 기호로 그렸습니다. 자세한 내용은 [그림 8-1](08_사출_순서도.md)에 있습니다.
- 관성 구간의 중단은 "중단 요인 발생?" 판단(예 → ABORT)으로 그렸습니다. 처리 상자마다 출구를 하나로 두기 위해서입니다.
- 모터 차단 판단의 원래 출구 라벨("CUT / THROTTLE 0", "아직")은 예/아니오로 바꾸고, 원래 라벨은 주 ⑪에 남겼습니다.
- 상세판에서 점선이었던 선은 I10 → RELEASED(`I10 -.-> RELD`)와 계획 → 정점 분리 판단(`APX -.-> RELQ`) 둘뿐입니다. I10 선은 점선 대신 빨강 실선(중단·안전 경로)으로 그렸고, 계획 선은 회색 파선(계획)으로 그렸습니다. I6 낙하 백업 선(`REL_I6 --> RELQ`)은 상세판과 같이 검은 실선입니다.
- 상자 제목 "사출", "하강", "회수", "탑재 차단"은 그림용 짧은 제목입니다. 내용은 주 ⑫, ⑳, ㉑에 있습니다.

## 주의

1. **차단 후 스핀:** I3 회전 중단은 POWERED에서만 평가합니다. 그래서 차단 후 약 1,390 °/s 스핀으로는 ABORT가 나지 않습니다(`onboard.c:282-289`; R2:412).
2. **비행 전 실측:** 비행 전 1 km 지상 통신 시험이 필요합니다. 정점 140-150 m에 낙하산 표류가 더해지면 Wi-Fi 거리에 가깝거나 그 밖일 수 있습니다(E)(FW:240-242).
3. **예전 검증 결과:** 아래는 30.3 N을 가정한 예전 본체의 결과이고, 새 본체 결과가 **아닙니다**(VAL:41-53).
   - 정점 127.6-149.1 m, 150 m 초과는 0/30
   - 착지점 평균 74-86 m 풍하
