# 07. 제어 루프 순서도 (One 250 Hz control cycle)

이 순서도는 펌웨어 `body-redesign` @ 78f59fa의 한 틱을 따라갑니다. 틱 길이는 4 ms입니다.

- **NAV(U1):** Timer2로 틱을 셉니다(`nav_main.c:273-442`).
- **FCU(U2):** 자체 틱 인터럽트 없이, nav 프레임이 도착하면 그 틱을 시작합니다(`main.c:1047-1410`).
- **COM(U3):** 마감이 없는 슈퍼루프입니다(`com_main.c:108-150`).
- **그림 구성:** 상세판의 한 그림(NAV와 FCU 두 줄)을 A4에 맞게 그림 7-1(NAV)과 그림 7-2(FCU)로 나눴습니다. 두 줄 사이의 화살표는 양쪽 그림에 같은 이름의 연결자 A, B로 남겼습니다. "다음 틱" 되돌림 선(왼쪽)은 250 Hz 반복을 보이려고 넣은 것이며 새 사실은 없습니다.
- Mermaid 원본은 [상세판](detailed/07_제어_루프_순서도.md)에 있습니다.

| 주 | 내용 |
|---|---|
| ① | NAV는 Timer2로 틱을 셉니다. Timer0 ISR이 틱 496 µs 전에 MPU-6050 버스트 읽기를 시작합니다(`nav_main.c:273-442`). |
| ② | 센서: 실패 카운터 유지. 연속 실패 25회째부터 26회마다 twi_recover. BMP280 단계 1개를 5틱마다(= 50 Hz) 처리합니다. |
| ③ | 패드 정렬("예" = on_pad): 자이로 바이어스 + 가속도 평균(N_avg 500), q = level_from_accel(roll, pitch, yaw 0) |
| ④ | 비행: 자이로만 쿼터니언 적분(바이어스 고정, 가속도 미사용). 펌웨어 추정기는 Mahony가 아니라 PadAlignGyroEstimator입니다. Mahony는 시뮬레이션 레거시 옵션입니다(`sim/sim6dof.py:43, 107, 172-180`). |
| ⑤ | 고도 필터 예측: h += v·dt + a·dt²/2, v += a·dt. 기압 보정: k1 = 2ζω_n, k2 = ω_n². f_c 0.4 Hz, ζ 0.7. 패드에서는 h = v = 0 유지. |
| ⑥ | nav 프레임: q, rate, accel, h, v_z, h_baro, tilt, 플래그(IMU_OK, BARO_OK, ALIGNED, EST_VALID 등) |
| ⑦ | nlink SPI 72 B 교환: 2 MHz, 약 630 µs. 틱 후 약 1.8 ms(패드) / 2.2 ms(비행)에 FCU로 전달됩니다. 연결자 A는 그림 7-2의 A로 이어집니다. 배경 단계(기압 보상 계산)는 다음 틱 450 µs 전까지 실행됩니다. |
| ⑧ | 다음 교환 때 FCU 상태가 전달됩니다. NAV의 패드/비행 전환은 2틱 늦습니다(`nlink_proto.h:47-51`). 연결자 B는 그림 7-2의 B에서 옵니다. |

출처: `nav_main.c:273-442, 45-47`; PG:56; `att_estimator.c:56-84`; `alt_filter.c:32-48`; PG:291-292. 모든 타이밍은 simavr·co-sim 값이며 하드웨어에서 측정한 적은 없습니다(SPEC:1401-1408).

### U2 FCU

![그림 7-2. U2 FCU의 한 틱 (nav 프레임으로 시작)](img/07_제어_루프_순서도_2.png)

**그림 7-2.** U2 FCU의 한 틱 (nav 프레임으로 시작) · [SVG](img/07_제어_루프_순서도_2.svg) · [PNG](img/07_제어_루프_순서도_2.png)

| 주 | 내용 |
|---|---|
| ① | FCU는 자체 틱 인터럽트가 없습니다. nav 프레임이 도착하면 틱을 시작하고, 없으면 4.6 ms 후 자체 시계로 시작합니다(`main.c:1047-1410`). 연결자 A = 그림 7-1의 nlink(NAV 데이터). 이 단계는 원문 ①로, 암 스위치를 5틱 디바운스합니다. |
| ② | ilink 수신(원문 ②): IL_CMD가 완성될 바이트만(16 B 이하). 다음 단계 감독기(원문 ③)의 내용은 그림 6-1, 6-2에 있습니다. |
| ③ | control_active = POWERED 또는 UNPOWERED 처음 0.5 s(`main.c:1168-1195`; `onboard.c:89-94`) |
| ④ | 자세 루프: q_sp = 무장 시 방위로 수직, e = rotvec(q_err), rate_sp = clip(Kp_att·e). Kp_att xy 2.930, z 1.055. rate_sp 한계 xy 2.5, z 1.5 rad/s(`attitude_ctrl.c:33-60`; `gains.h:15-18, 31`). |
| ⑤ | 레이트 PID(축마다): 자이로 LPF 80 Hz, D항 LPF 40 Hz. M = Kp·err + I - Kd·dω/dt. xy: Kp 1.970, Ki 0.643, Kd 0.0617, I_max 0.6 N m. z: Kp 0.102, Ki 0.130, Kd 0, I_max 0.15 N m. 포화 또는 추력 하한이면 적분 정지(`pid.h:1-12`; `attitude_ctrl.c:61-66`; `gains.h:19-29`). |
| ⑥ | 베인 믹서(회색 = 예전 본체 상수): T_hat = max(30.3·u², 0.25·T_max), k = T_hat·S_v·C_La / (2·A_e), d_x = M_x/(2·l_v·k), d_y = M_y/(2·l_v·k), d_z = 0.5·M_z/(4·r_v·k). 현재 값 l_v 0.3495 m, r_v 0.028 m, S_v 960 mm², C_La 2.4/rad, A_e 5073 mm², T_max 30.3 N(PG:124-131)은 예전 본체 값입니다. 새 본체 V 꼬리 팔은 272 mm입니다(NBS:1453). 갱신은 이후 제어 라운드로 미뤄졌습니다(PG:26-31; `gains.h:39` GAINS_PARAMS_STALE 1). |
| ⑦ | 베인 배분: 베인1 = d_x + d_z, 베인2 = d_y + d_z, 베인3 = -d_x + d_z, 베인4 = -d_y + d_z. 포화 시 롤 먼저 축소, 그래도 넘으면 롤 제거 후 비례 축소. |
| ⑧ | PWM = 1500 + 부호·deg·11.1 µs/deg + 트림. 명령 한계 20°, 1222.5-1777.5 µs(기계 25°)(`mixer.c:69-125`; `mixer.h:1-16`; PG:124-151; `gains.h:30`). control_active가 아니면 베인 중립 + 트림. |
| ⑨ | 원문 ④–⑥. 베인 PWM 즉시 기록(④)과 ESC = 1000 + u·1000 µs(POWERED만, ⑤) 다음에 이 단계(⑥)가 옵니다: 배터리 LPF, 이벤트 기록, IL_SNAP 캡처, 다음 nlink용 FCU 응답 프레임, LED·부저. 연결자 B = 다음 교환 때 FCU 상태 전달(NAV 패드/비행 전환은 2틱 지연, `nlink_proto.h:47-51`). |
| ⑩ | EDF 추력 추정(원문 ⑦): 기록만, τ 0.15 s. 5틱마다 비행 기록 'F' 50 Hz. |
| ⑪ | 배경: SNAP → COM, ilink, 기록 패킹, 'C'/'N'/'S' 레코드. 다음 교환 280 µs 전까지(`main.c:17-36, 1072-1367, 184-186`). |

구동기(50 Hz 프레임): 베인 서보 MG90S × 4(J8-J11), ESC → EDF, 분리 서보(J13). 분리 서보 PWM은 1000.5 / 1999.5 µs입니다. 축 정의: x, y는 측방향 축(피치, 요), z는 롤 축입니다. 롤 관성 Izz는 0.005 kg m²입니다(PG:172).

원문 노드 F1–F3, F11–F13의 단계 번호 ①–⑦은 주 번호와 겹치지 않도록 그림에서 뺐습니다. 순서는 흐름선이 보여 줍니다. 원래 번호는 위 주의 "원문 ①" 같은 표기로 남겼습니다.

## 주의

1. **추정기:** 펌웨어의 자세 추정기는 Mahony가 아니라 **PadAlignGyroEstimator**입니다. Mahony는 시뮬레이션의 레거시 옵션으로만 남아 있습니다(`sim/sim6dof.py:43, 107, 172-180`).
2. **타이밍 수치:** 모든 타이밍은 simavr·co-sim 값입니다. 하드웨어에서 측정한 적은 없습니다(SPEC:1401-1408).
3. **축 정의:** x, y는 측방향 축(피치, 요)이고 z는 롤 축입니다. 롤 관성 Izz는 0.005 kg m²입니다(PG:172).
4. **믹서 플랜트 상수(그림 7-2의 회색 상자)는 예전 본체 값입니다.** 현재 값은 l_v 0.3495 m, r_v 0.028 m, S_v 960 mm², C_La 2.4/rad, A_e 5073 mm², T_max 30.3 N(PG:124-131)이고, 새 본체의 V 꼬리 팔 길이는 272 mm입니다(NBS:1453). 갱신은 이후 제어 라운드로 미뤄졌습니다(PG:26-31; `gains.h:39` GAINS_PARAMS_STALE 1).
